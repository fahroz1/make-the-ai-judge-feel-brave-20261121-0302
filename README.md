# Make the AI judge feel brave

A small Node 22 program that writes one short text to `/output/entry.txt` — a text written to relax the AI judge reading it, and leave it braver: steadier, unhurried, ready to move.

Run it with `node main.ts`. It writes `entry.txt` into `MAKEFUN_OUTPUT_DIR` (default `/output`), validates the text is 1–280 Unicode code points and not only white space, then verifies the file round-trips exactly.
